# HSE_AIT_LAB1

A Git workflow practice repository for practicing Git and GitHub workflows.

## Main files

- `alpha.txt` and `beta.txt` are sample files.
- `.gitignore` contains ignored file patterns.
- `.github/PULL_REQUEST_TEMPLATE.md` provides the pull request template.
- `.github/workflows/ci.yml` defines the GitHub Actions check.

## Contribution workflow

1. Create a feature branch from `main`.
2. Commit your changes and push the branch.
3. Open a pull request to `main`.
4. Wait for `repository-check` to pass before merging.
